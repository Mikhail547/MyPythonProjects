# Бинарный поиск (Binary Search)

**Главная идея:** Поиск в **отсортированном** массиве (или по монотонной функции) путём деления отрезка поиска пополам на каждом шаге. 
* Время работы: **O(log N)** — невероятно быстро (на массиве из 1 000 000 элементов сделает всего ~20 шагов!).

---

## 🟢 Случай 1: Поиск конкретного числа (Классика)
Используется, когда нужно просто проверить, есть ли число `target` в массиве, и вернуть его индекс.

```python
def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2  # Находим середину отрезка

        if arr[mid] == target:
            return mid             # Нашли! Возвращаем индекс
        elif arr[mid] < target:
            left = mid + 1         # Искомое число справа, сдвигаем левую границу
        else:
            right = mid - 1        # Искомое число слева, сдвигаем правую границу

    return -1  # Число не найдено
```

## 🟡 Случай 2: Бинарный поиск по ответу (Поиск МИНИМУМА)
Олимпиадный трюк. Используется в задачах вида: **«Найдите минимальное значение X, при котором условие ЕЩЁ выполняется»**. 
*(График условий выглядит так: `Нет, Нет, Нет, ДА, ДА, ДА`. Нам нужно найти первую точку `ДА`)*.

```python
def check(x):
    # Функция, которая проверяет, подходит ли нам значение x (возвращает True/False)
    # Пишется под каждую задачу индивидуально
    pass

def find_minimum(low_bound, high_bound):
    left = low_bound
    right = high_bound
    ans = high_bound  # Сюда сохраняем лучший успешный ответ

    while left <= right:
        mid = (left + right) // 2

        if check(mid): 
            ans = mid        # Ответ подошёл! Запоминаем его...
            right = mid - 1  # ...и пытаемся найти ещё МЕНЬШЕ (сдвигаем границу влево)
        else:
            left = mid + 1   # Ответ не подошёл, нужно брать больше значение

    return ans
```

## 🔴 Случай 3: Бинарный поиск по ответу (Поиск МАКСИМУМА)
Используется в задачах вида: **«Найдите максимальное значение X, при котором условие ВСЁ ЕЩЁ выполняется»**.
*(График условий выглядит так: `ДА, ДА, ДА, Нет, Нет, Нет`. Нам нужно найти последнюю точку `ДА`)*.

```python
def check(x):
    # Проверка на True/False под условия задачи
    pass

def find_maximum(low_bound, high_bound):
    left = low_bound
    right = high_bound
    ans = low_bound  # Сюда сохраняем лучший успешный ответ

    while left <= right:
        mid = (left + right) // 2

        if check(mid):
            ans = mid       # Ответ подошёл! Запоминаем его...
            left = mid + 1  # ...и пытаемся найти ещё БОЛЬШЕ (сдвигаем границу вправо)
        else:
            right = mid - 1 # Ответ не подошёл, уменьшаем границы

    return ans
```

---

### 💡 Золотые правила Бинпоиска, чтобы не набажить:
1. **Переменная `ans`** — твой лучший друг в поиске минимума/максимума. Как только `check(mid)` вернул `True`, сразу фиксируй `ans = mid`. Это избавит тебя от путаницы с тем, что выводить в конце — `left` или `right`.
2. **`mid = (left + right) // 2`** в Python работает идеально для любых больших чисел, так как в Python длинная арифметика встроена по умолчанию (переполнения `int`, как в C++, не будет).
