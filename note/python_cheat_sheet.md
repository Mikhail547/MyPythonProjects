## 🟩 1. СТРОКИ (`str`) — Неизменяемый тип данных!
*Любой метод строки возвращает новую строку, старую изменить нельзя.*

*   `s.strip()` — Удаляет пробелы (и невидимый `\n` от быстрого ввода) с обоих концов строки [363B].
*   `s.split()` — Разбивает строку на список по пробелам. Если передать аргумент: `s.split(',')` — разобьет по запятым.
*   `' '.join(список)` — Склеивает список строк в одну большую строку через указанный разделитель. **(Работает за линейное O(N), очень быстро!)**.
*   `s.lower()`, `s.upper()` — Переводит всю строку в нижний или верхний регистр.
*   `s.count(sub)` — Считает, сколько раз подстрока `sub` встречается в строке `s`.
*   `s.find(sub)` — Возвращает индекс первого вхождения подстроки. Если не найдено, возвращает `-1`.
*   `s.replace(old, new)` — Заменяет все вхождения `old` на `new`.
*   `s.isdigit()` — Проверяет, состоит ли строка только из цифр (возвращает `True/False`).
*   `s[::-1]` — Разворот строки (срез) [363B].

## 🟦 2. МАССИВЫ / СПИСКИ (`list`) — Динамический массив
*Поиск элемента по значению занимает O(N). Доступ по индексу `arr[i]` занимает O(1).*

*   `arr.append(x)` — Добавляет элемент `x` в конец списка **(O(1))**.
*   `arr.pop()` — Удаляет и возвращает последний элемент списка **(O(1))**.
*   `arr.pop(0)` — Удаляет первый элемент. **❌ НЕ ИСПОЛЬЗОВАТЬ НА ОЛИМПИАДАХ!** Работает за O(N), так как сдвигает весь массив. Вместо этого используй `from collections import deque` и её метод `popleft()`.
*   `arr.insert(index, x)` — Вставляет `x` на позицию `index`. **🐌 Осторожно, O(N)**.
*   `arr.remove(x)` — Удаляет первое вхождение элемента `x` из списка. **🐌 Осторожно, O(N)**.
*   `arr.sort()` — Сортирует исходный список на месте **(\(O(N \log N)\))**.
*   `sorted(arr)` — Функция, которая возвращает новый отсортированный список, не изменяя старый **(\(O(N \log N)\))**.
*   `arr.reverse()` — Разворачивает список на месте **(O(N))**.
*   `arr.count(x)` — Считает количество элементов `x` в списке **(O(N))**.
*   `min(arr)`, `max(arr)`, `sum(arr)` — Нахождение минимума, максимума и суммы массива за один проход **(O(N))**.

## 🟨 3. ХЕШ-ТАБЛИЦЫ — МНОЖЕСТВА (`set`) и СЛОВАРИ (`dict`)
*Все базовые операции (поиск, добавление, удаление) работают за волшебное **O(1)**.*

### Множества (`set`):
*   `my_set = set()` — Создание пустого множества.
*   `my_set.add(x)` — Добавить элемент в множество. Если он там уже был, ничего не изменится.
*   `my_set.remove(x)` — Удалить элемент. Если элемента нет, выбросит ошибку.
*   `my_set.discard(x)` — Безопасное удаление: если элемента нет, ошибки не будет.
*   `if x in my_set:` — Проверка, есть ли элемент в множестве. **(O(1) — главное олимпиадное оружие!)**.

### Словари (`dict`):
*   `my_dict = {}` — Создание пустого словаря.
*   `my_dict[key] = value` — Добавление пары ключ-значение или перезапись, если ключ существовал.
*   `del my_dict[key]` — Удаление ключа и его значения из словаря.
*   `my_dict.get(key, default)` — Безопасное чтение ключа. Если ключа нет, вернет значение `default` (например, 0), вместо падения с ошибкой.
*   `my_dict.keys()` — Возвращает список всех ключей словаря.
*   `my_dict.values()` — Возвращает список всех значений.
*   `my_dict.items()` — Возвращает пары `(ключ, значение)` для перебора в цикле:
    ```python
    for key, value in my_dict.items():
        print(key, "встретился", value, "раз")
    ```
