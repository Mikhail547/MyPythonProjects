# Поиск в ширину (BFS — Breadth-First Search)

**Главная идея:** Алгоритм обхода графа, который работает «волнами». Мы сначала посещаем стартовую вершину, затем всех её ближайших соседей (1 шаг), затем соседей наших соседей (2 шага) и так далее.
* **Главное свойство:** Если все ребра графа имеют одинаковую длину (вес = 1), BFS **гарантированно находит кратчайший путь** от стартовой вершины до всех остальных.
* Время работы: **O(V + E)**, где V — число вершин, E — число ребер. Алгоритм работает линейно и очень быстро.

---

## 🛠️ Главный инструмент: Двусторонняя очередь (`deque`)
Для BFS обычный Python-список `list` использовать **нельзя**, так как удаление элемента из начала списка `arr.pop(0)` работает за медленное O(N). 
Мы используем специальную структуру `deque` из модуля `collections`. Операция `popleft()` в ней работает мгновенно — за **O(1)**.

---

## 🟢 1. Классическая реализация BFS для Графа

Используется, когда граф задан списком смежности (каждая вершина хранит список своих соседей).

```python
from collections import deque

def bfs(start_node, graph, n):
    # Массив расстояний. Изначально везде бесконечность (-1)
    dist = [-1] * (n + 1) 
    
    queue = deque([start_node]) # Кладем стартовую вершину в очередь
    dist[start_node] = 0        # Расстояние до самого себя равно 0
    
    while queue:
        current = queue.popleft() # Достаем вершину из начала очереди
        
        # Проверяем всех соседей текущей вершины
        for neighbor in graph[current]:
            if dist[neighbor] == -1: # Если соседа еще не посещали
                dist[neighbor] = dist[current] + 1 # Шаг вперед
                queue.append(neighbor) # Добавляем соседа в конец очереди
                
    return dist # Возвращает расстояния от старта до всех вершин
```

## 🟡 2. Поиск пути в Лабиринте / Матрице (Самый частый олимпиадный тип)

Используется, когда нужно найти кратчайший путь на клетчатом поле (матрице), где есть стены `#` и свободные клетки `.`.

```python
from collections import deque

def bfs_maze(start_x, start_y, target_x, target_y, maze):
    rows = len(maze)
    cols = len(maze[0])
    
    # Массив для хранения расстояний до каждой клетки
    dist = [[-1] * cols for _ in range(rows)]
    
    queue = deque([(start_x, start_y)])
    dist[start_x][start_y] = 0
    
    # Вектора сдвигов для ходов: Вверх, Вниз, Влево, Вправо
    dx = [-1, 1, 0, 0]
    dy = [0, 0, -1, 1]
    
    while queue:
        x, y = queue.popleft()
        
        if x == target_x and y == target_y:
            return dist[x][y] # Нашли конечную цель! Возвращаем длину пути
            
        # Пробуем сделать шаг во все 4 стороны
        for i in range(4):
            nx = x + dx[i]
            ny = y + dy[i]
            
            # Проверяем, что не вышли за границы поля, там нет стены '#' и мы там не были
            if 0 <= nx < rows and 0 <= ny < cols:
                if maze[nx][ny] != '#' and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    queue.append((nx, ny))
                    
    return -1 # Если до цели дойти невозможно
```

## 💡 Золотые правила BFS, чтобы не набажить:
1. **Фиксация посещения:** Запоминай, что вершина посещена (`dist[neighbor] = ...`) **в тот самый момент, когда ты добавляешь её в очередь (`queue.append`)**, а не тогда, когда ты достаёшь её оттуда. Если делать это при извлечении, одна и та же вершина успеет добавиться в очередь сотни раз, и код упадёт по памяти.
2. **Восстановление пути:** Если в задаче просят вывести не просто длину пути, а сам маршрут (последовательность вершин), заведи массив `parent = [-1] * N`. При переходе `parent[neighbor] = current`. В конце по этой цепочке можно легко отмотать путь назад от финиша к старту.
