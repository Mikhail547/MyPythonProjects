### 🛠️ Идеальный шаблон для поиска суммы на отрезке [L, R] (1-индексация)

```python
def build_prefixes(arr):
    # Создаем массив префиксов длины N + 1, заполненный нулями
    pref = [0] * (len(arr) + 1)
    for i in range(1, len(arr) + 1):
        pref[i] = pref[i-1] + arr[i-1]
    return pref

# Пример использования:
arr = [3, 5, 1, 4, 2]
pref = build_prefixes(arr)  # Будет: [0, 3, 8, 9, 13, 15]

# Запрос: Найти сумму с 2-го по 4-й элемент (числа 5, 1, 4. Сумма = 10)
# В олимпиадах отрезки часто задают в 1-индексации
L, R = 2, 4 
result = pref[R] - pref[L-1]  # pref[4] - pref[1] = 13 - 3 = 10
print(result) # Мгновенный ответ без циклов!
```
