# Метод двух указателей (Two Pointers)

**Суть метода:** Замена медленного вложенного цикла O(N²) на один быстрый проход O(N) с помощью двух переменных-индексов (указателей).

### Классический шаблон (Движение навстречу друг другу):
Применяется на **отсортированном** массиве для поиска пары чисел.

```python
left = 0
right = len(arr) - 1

while left < right:
    current_sum = arr[left] + arr[right]
    if current_sum == target:
        print("Найдено:", left, right)
        break
    elif current_sum < target:
        left += 1   # Увеличиваем сумму, двигая левый указатель вправо
    else:
        right -= 1  # Уменьшаем сумму, двигая правый указатель влево
```
