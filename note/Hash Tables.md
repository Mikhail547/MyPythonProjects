### 💡 Главные фишки для олимпиад:
1. **Множества (`set`)** хранят только уникальные элементы. Идеальны для проверки «был ли элемент раньше».
2. **Словари (`dict`)** идеальны для подсчета частоты элементов (сколько раз встретилось число/буква).
3. Чтобы не писать проверку `if key not in d:`, используй `from collections import defaultdict`.

```python
from collections import defaultdict

# Умный словарь, где по умолчанию для каждого ключа значение равно 0
counter = defaultdict(int)

# Теперь можно сразу прибавлять единицу, Python сам создаст 0, если ключа нет
counter['apple'] += 1 
```
